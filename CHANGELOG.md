# Changelog

All notable changes to ux-crux are documented here. Versioning follows SemVer; the whole plugin is versioned as one unit (see `src/skills/review/references/review-model.md`'s sibling design note in `design.md` for why).

## 0.1.23 — full-coverage review mode, exhaustive report citations, and a mobile-web applicability fix

Behavioral/reporting change, not a rule-catalog addition — no rule IDs were added, removed, or renumbered. Prompted by a Smart-vs-Full empirical comparison (a 21-rule `accessibility` fixture and a 134-rule `usability` fixture, each with a known set of planted violations) that validated three fixes:

- `src/shared/report-contract.md`: the Moderate/minor findings section now carries the same "every finding" guarantee as Blockers/Major (previously "for completeness" read weaker), and every report section — including each Category Health line and each Top-3 item, not only individual finding blocks — must now cite the rule ID(s) it is based on; the worked example was extended to demonstrate both. This closes a gap the experiment reproduced directly: individual findings already cited their rule correctly, but Category Health and Top-3 stayed untraceable prose.
- `usability`: `references/mobile.md` and `SKILL.md` now distinguish genuinely native-only platform contracts (`N02R`-`N04R`, `T06`-`T09`) from mobile-viewport-general rules that also apply to mobile web (`L01`, `L05`, `L07`, `L08` — safe-area handling, dark/increased-contrast appearance, localization text-expansion, scalable font units). Previously, evidence identified as mobile web (not native) caused the whole file to be skipped; the experiment's Full-mode run caught four real findings there (missing dark-mode variant, fixed-px fonts, a control with no safe-area handling, fixed-width labels that would break under localization) that the default run missed entirely.
- All six skills (`review`, `usability`, `psychology`, `accessibility`, `product`, `trust`) gain an opt-in "Full" mode: passing an argument recognizable as "full" triggers a mandatory, exhaustive rule-by-rule sweep of every reference file the request would otherwise load, instead of today's judgment-driven rule selection (which remains the default, via no argument or an explicit "smart" argument). The experiment found default judgment-driven selection already reaches full recall on directly-evidenced violations at negligible extra cost on a small rule catalog, but Full mode costs meaningfully more on a large one (+28% tokens / +91% wall time on the 134-rule `usability` catalog vs. +3% tokens / ~0% time on the 21-rule `accessibility` catalog) — so it ships as an explicit, costed opt-in rather than a new default. Each skill's `description` documents the accepted `full`/`smart` values in prose, since a marketplace-distributed `SKILL.md` package cannot currently drive CLI `argument-hint` autocomplete (a known Claude Code limitation, anthropics/claude-code#18364).

## 0.1.22 — sign-reliance, wait-design, activity-centered controls, and four other additions from a Living with Complexity comparison pass

Added a set of specific, named-source rule additions found while comparing this project's existing catalog against Don Norman, *Living with Complexity* (MIT Press, 2010) — a 9-chapter examination of why complexity is necessary, how it differs from confusing "complicatedness," and how good design tames it through structure, signifiers, and a designer/user partnership. Two prior Norman-adjacent passes (0.1.7's *The UX Book*, source of this project's affordances framework, and 0.1.18's *Design for a Better World*) already absorbed a large share of this author's vocabulary, so the overlap here is real: the Four Kinds of Affordances (`usability`'s `AF01`-`AF04`), defaults (`usability`'s `F21`, `psychology`'s `PB01`/`PB02`), error-prevention-over-messages (`usability`'s `E01`), expert-centric IA mismatch (`product`'s `IA01`/`IA04`), interruption resilience (`psychology`'s `PC06`), and security-usability friction (`usability`'s `F10`/`F11`) were all confirmed already covered and enriched with this book's sharper citations and examples rather than duplicated. Not a wholesale import of the book's full 34-item extraction — its service-design content (Frontstage/Backstage architecture, Expressive Service Blueprinting, the Amtrak Acela/iPod systems-level root-cause case studies), physical queue-topology engineering (single-line multi-server routing, spatial/temporal double buffering), distribution-channel/sales-force bias, and organizational over-measurement critique describe how a service organization runs its own operations or sells through a channel, not what a static-evidence UI/feature review checks, consistent with every prior comparison pass's treatment of process/methodology content.

- `usability`: new `AF05` in `references/affordances.md` — a persistent instructional label, warning sticker, or tooltip the design itself adds to compensate for a control's own confusing operation is evidence the design failed, not a mitigation to credit; the design-side counterpart to `AF02`'s user-side workaround signal, excluding legally mandated warnings.
- `usability`: new `S13` in `references/core.md`'s System status table — a wait/queue experience (checkout processing, matchmaking, a support-ticket queue, an onboarding delay) sets a conservative duration/position expectation, keeps the user occupied, treats all waiting users under one visibly fair order, and ends on a clear resolution (the Six Principles of Wait Design, via David Maister), distinct from `S03`/`S04`'s loading-indicator-type scope.
- `usability`: new `N23R` in `references/core.md`'s Navigation table — a multi-step wizard shows the current step and total/expected remaining steps, or an explicit not-yet-knowable signal (Nievergelt & Weydert's Sites/Modes/Trails framework), the forward-looking dimension neither `N16R` (breadcrumbs) nor `C03` (label consistency) requires.
- `usability`: new `E09` in `references/core.md`'s Errors & recovery table — a long, sequential, high-consequence procedure prone to memory failure under stress provides an interactive checklist with persistent state that surfaces skipped steps, distinct from `CR01`'s single-action emergency scope.
- `psychology`: new `PC09` in `references/cognitive.md` — the cumulative burden of many individually-simple, idiosyncratic interactions across a product (per-item confirmations, inconsistent toggles, repeated micro-permissions) is a system-level load in its own right, distinct from `PC01`'s single-task scope.
- `product`: new `IA10` in `references/information-architecture.md` — controls for a goal spanning multiple modules or subsystems are grouped by the user's named activity, not by which module owns them (goal-task-tool mismatch and activity-centered modularization — the Logitech Harmony remote), distinct from `IA01`'s content/navigation scope.
- `product`: new `P11` in `references/core.md`'s Purpose & task table — instructional/coaching content is delivered in-context at the moment a feature is attempted or needed, not front-loaded as a mandatory upfront tour, distinct from `P07`'s first-use/repeat-use/expert-use differentiation, which does not specify delivery timing.
- Citation-only enrichments (no new rule IDs, no behavior change): `usability`'s `E01` gains Norman's "the natural world has no error messages" framing; `usability`'s `F10`/`F11` gain the security-usability inverse paradox and its 5,000-password anecdote; `psychology`'s `PC01` gains the multiplicity/scaling-problem framing as context for `PC09`; `psychology`'s `PC08` gains the perceived-vs-operational-simplicity framing (the scientific-calculator example); `psychology`'s `PC06` gains the "welcome back" interrupted-form example; `psychology`'s `PB01`/`PB02` gain the opt-in-vs-opt-out pension-enrollment example; `product`'s `IA01`/`IA04` gain the expert-centric-taxonomy example (field-guide/lab-value cases); `product`'s `C04` gains the "no error messages in nature" framing.
- The rule catalog now spans 330 rule rows across all six skills (up from 323), continuing this project's practice of naming the current total in `README.md`'s opening paragraph.

## 0.1.20 — design-system consistency, sensitive-domain dignity, and non-interfering platform branding from a *How Design Makes Us Think and Feel and Do Things* comparison pass

Added a small set of specific, named-source rule additions found while comparing this project's existing catalog against Sean Adams, *How Design Makes Us Think and Feel and Do Things* (Adams Morioka / Chronicle Books, 2021) — a book examining the psychological and emotional mechanisms of graphic, brand, and industrial design across 13 chapters (seduction, efficiency, love, humor, intelligence, elegance, pride, innovation, innocence, nostalgia, anger, pleasure, honesty). Not a wholesale import of that book's full extracted 28-item set — the majority of its content (biomorphic ergonomics of physical hardware controls; a 100-logo dynamic brand-identity library and heroic campaign imagery for collective mobilization; pharmacy/OTC packaging combined with smart-kiosk and home-calendar syncing; curated-gallery/low-pressure retail layout) describes physical-hardware design, brand-identity systems, or single-industry verticals this project's prior comparison passes have consistently excluded, consistent with every one of this project's 19 prior comparison-pass entries' treatment of such content — and the book's own "Possible Omissions" self-audit acknowledges its primary domain is graphic/industrial design, not software interaction mechanics. Two of the book's own claims were evaluated against this project's standing evidentiary bar and rejected as unverified pop-psychology assertions with no independently citable research source: "pure primary colors are processed by the brain without complex decoding" and "golden-ratio horizontal aspect ratios align with evolutionary scanning biology" — the same bar that led the 0.1.6 pass to debunk the unsourced "Miller's Law caps navigation at 7" claim and the 0.1.14 pass to reject this same book's own uncited "Rule of Odds." Several items were confirmed already covered and left untouched: glossy visual veneer over broken function (`psychology`'s `PE01`/`PE06`/`PE07`), onboarding/unboxing friction elimination (`trust`'s `O01`-`O03`, `product`'s `P03`/`P06`), physical/interface constraints preventing errors (`usability`'s `E01`), open-ended narrative brand storytelling (out of scope per `VT05`), imperative call-to-action verbs (`usability`'s `A02R`, `accessibility`'s `X14`), wayfinding/real-time status in multi-step flows (`usability`'s `S04`/`R02R`/`R03R`/`N16R`/`CR01`), and fabricated scarcity/countdown urgency (already Blocker-severity `PB08`).

- `usability`: new `A17R` in `references/core.md`'s Actions table — a design system limits functionally-equivalent visual variants (button styles, font weights/families, colors for the same semantic purpose) to a small, deliberate set, rather than letting them proliferate unconstrained across screens (Herbert Bayer's Universal Typeface; Stockholm Design Lab's Askul packaging system).
- `psychology`: new `PE08` in `references/emotion.md` — a sensitive-domain form (health, financial hardship, body/clothing sizing) replaces a clinical or intimidating category label with a neutral, familiar alternative that does not compromise accuracy, distinct from `product`'s `C15` (disability-language dignity) and `trust`'s `O13` (gender/identity field structure) (Guan-Hao Pan's *Love Guide Condoms* sizing redesign).
- `psychology`: new `PB14` in `references/behavioral-economics.md` — a guilt-bridging "earned reward" frame for a purchase/upgrade/leisure feature is permitted only when the user's effort is genuine and truthfully represented, subject to the standing four-gate ethics test; fabricated or exaggerated effort is a deceptive-framing finding (McDonald's "You deserve a break today").
- `product`: new `VT06` in `references/voice-tone.md` — a non-error, human/administrative notification carrying unwelcome news (an overdue-payment notice, a policy-violation warning, a downtime alert) may use light, self-aware tone; explicitly does not override `usability`'s `E02`/`E03` for genuine system errors, and never applies to security-breach or safety-critical notifications.
- `product`: new `C27` in `references/web.md` — long-form/editorial text renders at roughly 50-70 characters per line with a proportional heading-to-body type scale, continuing the file's `C07`-`C12` scanning/typography set (classical book-page proportions; NN/g line-length guidance).
- `product`: three new rules in `references/core.md`'s Content table — `C28` (a medical/legal/grave/trauma-related screen uses objective, restrained visual tone rather than cheerful or patronizing stock imagery, the visual counterpart to `C15`'s language-level neutrality), `C29` (a product for children/teens/older adults avoids age-patronizing visual tropes — fake handwriting fonts, chaotic decoration, artificial dumbing-down — parallel to `C15` but keyed to age), and `C30` (a platform hosting user-generated/curated content keeps its own branding minimal and non-competing, no animated logos or aggressive watermarks over the content).
- `accessibility`: new `X16` in `references/mobile.md` — mobile typography/iconography remain legible under real-world adverse conditions (outdoor glare, low-resolution displays, low ambient light), distinct from `core.md`'s `X03` (static contrast) and this file's `X04`/`X05` (text-scaling support) (Matthew Carter's Bell Centennial ink-trap engineering).
- `product`: citation-only enrichments (no new rule IDs, no behavior change) — `C20`/`C22`/`C25`/`C26` gain a citation to Marvin Minsky's ingredients-of-intelligence framing (subgoals, sub-objects, cause-symbols) as an additional named source for structuring dense data displays; `C23` gains a citation naming deliberately raw/unpolished visual production as a signal of urgency or grassroots authenticity, the inverse case informing its existing polish-vs-trust judgment.

## 0.1.18 — delayed-feedback loops, crisis interaction, societal affordances, and seven targeted rule additions from a Design for a Better World comparison pass

Added a set of specific, named-source rule additions found while comparing this project's existing catalog against Don Norman, *Design for a Better World: Meaningful, Sustainable, Humanity Centered* (MIT Press, 2023) — a wide-ranging critique spanning artificial systems, meaningful communication of complexity, sustainable/circular design, humanity-centered design process, and human cognitive/behavioral factors. Not a wholesale import of that book's full extracted 20-item set — its physical-product circular-economy content (obsolescence modes, Product-as-a-Service transformation, material-bonding/recyclability limits) describes hardware manufacturing and business-model decisions, not a reviewable software interface pattern, and its one adjacent concern (hardware-tier/connectivity equity) is already covered by `accessibility`'s `X15`; its Five Principles of Humanity-Centered Design (ecosystem focus, decades-scale impact, designing with/by communities) describes strategic/organizational-scale intent, not something checkable from a static UI/flow evidence review; its Incremental Modular Design, Agile/MVP/sprint methodology, and "Designer as Orchestral Conductor" team-facilitation material describe how a team runs its own process, not what a static-evidence review checks, consistent with every prior comparison pass's treatment of process content; and Goodhart's Law / the proxy-measurement trap describes internal team/organizational metric design, with its one adjacent case (a gamified metric rewarding the wrong proxy) already covered by `psychology`'s `PG02`. Two items were folded into citation-only enrichments of existing rules rather than added as standalone rules: Searchers vs. Planners / Convivial Tools (already `usability`'s `AF02` territory) and tightly-vs-loosely-coupled system architecture (already `usability`'s `S10` territory).

- `usability`: new `S12` in `references/core.md`'s System status table — a control whose real-world effect is not immediate (a temperature setting, a background sync toggle) shows the expected rate/delay explicitly, correcting the specific mental-model failure where a hidden long-delay feedback loop causes users to push a control to an extreme value (Norman's air-conditioner/thermostat case), distinct from `S01`'s general feedback-presence requirement and `S04`'s progress-indication requirement.
- `usability`: new "Crisis & high-stress interaction" section in `references/core.md` with `CR01` — an emergency/safety-critical/acutely time-pressured flow collapses its primary response to one prominent, immediately actionable control rather than requiring multi-step reasoning or dense reading, since stress and time pressure shift users toward fast, visceral processing (Norman's SCUBA weight-belt-drowning case, pediatric-ICU alarm-cacophony case); does not apply to calm, non-urgent flows.
- `usability`: new `AF04` in `references/affordances.md` — a societal (convention-based, not physical) affordance: a control an action the system technically permits but that carries an unwritten social, reputational, or procedural cost requires a clear signifier warning the user, a distinct framework from `AF01`'s four physical/cognitive/sensory/functional affordance types, not a fifth row in that table.
- `product`: two new rules in `references/core.md`'s Content table — `C25` (the Single Aggregate Number Fallacy: a composite dashboard/score must not blend trade-off dimensions into one number with no drill-down, Kate Raworth's Doughnut Model and the GDP-pollution-counted-as-positive critique, distinct from `C20`'s audience-complexity scope and `C22`'s chart-type-fit scope) and `C26` (narrative-context grounding: a data-dense screen about a human subject keeps a visible human/narrative anchor alongside clinical/numeric fields, Norman's "Medical Cart Syndrome"). New `P10` in the Purpose & task table — the semi-automation passive-monitoring complacency trap: a semi-autonomous feature handing control back to a passively monitoring human only at the moment of failure, with no lead time, is a design defect requiring full automation or active-engagement checkpoints, distinct from `usability`'s `IE14` (interruption during active use, not vigilance decay during passive monitoring).
- `trust`: new `PR02` in `references/core.md` — invisibility of prevention: a background protective/maintenance system that works silently (a security scan, an auto-backup, threat blocking) surfaces periodic, non-intrusive activity summaries, since unexplained silence reads as proof the protection was unnecessary and invites users to disable it (Norman's COVID-precaution-backlash case), distinct from `S08`'s opposite-direction caution against noisy confirmation of trivial user-initiated actions.
- `review`: new "Legacy Assumption Audit" technique note in `references/review-model.md` (non-rule, same precedent as the existing Role-Play UI Audit) — an iterative "why" probe for when a UI requirement's only stated justification is precedent, testing whether it is a genuine current need or an obsolete administrative remnant (Norman's healthcare-data-entry case), cross-referenced from `V06`'s named-technique list.
- Citation-only enrichments (no new rule IDs, no behavior change): `psychology`'s `PB03` gains a citation naming Herbert Simon's satisficing/bounded-rationality research and the decoy effect explicitly; `psychology`'s `PC01`/`PC08` gain the same Simon citation as additional backing for extraneous-cognitive-load reduction; `usability`'s `AF02` gains a citation to Eric von Hippel's Lead User theory and the IKEAhackers.net case as reinforcing evidence that user-built workarounds are a legitimate design signal; `usability`'s `E01` gains a direct citation to Norman's "human error is design error" framing; `usability`'s `S10` gains a citation naming tight/loosely-coupled systems (Toyota JIT vs. Internet routing) as the underlying resilience concept.
- The rule catalog now spans 311 rule rows across all six skills (up from 305), continuing this project's practice of naming the current total in `README.md`'s opening paragraph.

## 0.1.17 — a new gamification-mechanics reference file and eight targeted rule additions from a Seductive Interaction Design comparison pass

Explicitly positioned as the complementary legitimate-use side of the same territory `PB12`/`PH01`-`PH04` already cover from the guardrail side, not a duplicate or a replacement.

The "Search & discovery" section is renamed "Search, discovery & comparison" and gains `D06` — keep compared decision parameters (price/schedule, spec/cost) in tight horizontal proximity (the KLM flight-search redesign case). The "Always show onboarding" folk-rule guard gains a concrete citation (a mobile instruction-popup study: near-zero fixation time, 100% subsequent task failure).
- `psychology`: new `PA10` — F-pattern/top-left scanning bias in dense single-column text, and how multi-column/structured-block formatting disperses fixations; framed alongside `PA01`/`PA04` in `attention.md`.
- `product`: new `P09` — on a product-detail (single-featured-item) page, cross-sell/recommendation modules must not sit above the primary featured product; scoped by an applicability note (does not apply to browse/category/listing pages), distinct from the general `P02` hierarchy rule. New reference file `references/web.md` (the `web.md` addendum already anticipated in this project's config context) with six text-scanning/typography rules (`C07`-`C12`) for content-heavy pages: inverted-pyramid structure, front-loaded headline/subheading keywords, an ALL-CAPS reading-speed penalty, left-alignment primacy over centered/justified body text, digit-not-word numerals, and image captions as a high-fixation content element.

## 0.1.8 — five targeted rule additions from a Digital Minimalism comparison pass

Added a small number of specific, named-source rule additions found while comparing this project's existing catalog against Cal Newport's *Digital Minimalism*. Not a wholesale import of that book's ~12 extracted items (its attention-economy philosophy, digital-declutter process, solitude/default-mode-network framing, single-purpose computing, slow media, and community-organizing content stay deferred per `openspec/config.yaml`, and its core variable-reward/streak/autoplay/stopping-cue mechanisms were already covered by this project's existing `PH02`-`PH04` and four-gate ethics test) — each addition traces to a named, verifiable primary source, consistent with every other rule in this project.

- `product`: new `P08` — a feature, permission request, or onboarding flow must state a concrete user value, why it's the best available way to serve it, and explicit operating boundaries; a vague, open-ended value proposition ("stay connected," "never miss out") does not justify unconstrained access (Stanford Behavior Design Lab/Fogg Behavior Model; Apple/Android permission guidance). Distinct from the existing `P06` (identity/data gating only).
- `trust`: new `O11` — notification controls should support time-based quiet hours and sender/contact-level allowlisting, not only category toggles (Apple Focus; Android Do Not Disturb + priority senders). ## 0.1.4 — remote install verified; manifest-location false start reverted
