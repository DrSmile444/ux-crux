## Context

See `proposal.md`. IDs `A32R` and `E10` were verified free by grep; each lives in exactly one file.

## Decisions

- `A32R` sits in `usability/references/core.md` after `A31R` (controls); `E10` sits after `E09` (errors). Both are platform-agnostic.
- `A32R` carries `Strong` because the spatial stimulus-response compatibility effect (Fitts and Seeger, 1953) shows faster and more accurate responses when the response set corresponds spatially to the stimulus set; the rule is worded to that effect and cites the book for the interface application.
- `E10` carries `Expert practice`: the book states the practice without a study, and the corroboration search found nothing contradicting it. The rule asks for confirmation, not blocking, so an unusual but valid value stays possible.
- Citations are added to existing rules only where the book states the same practice in the chapter named.
