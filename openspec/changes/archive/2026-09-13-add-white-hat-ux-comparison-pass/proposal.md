## Why

A targeted comparison pass against Trine Falbe, Martin Michael Frederiksen & Kim Andersen, *White Hat UX: The Next Generation in User Experience*, found twelve concrete gaps in the existing rule catalog — mechanisms this book documents with named, independently verifiable grounding (Gestalt's Law of Similarity, NN/g's Deceptive Patterns research, WCAG-adjacent authentication/consent concerns, standard checkout-transparency findings) that no current rule in `usability`, `psychology`, `trust`, or `product` covers, even approximately. This follows the same targeted-comparison-pass pattern already used for five prior books/research syntheses (see `CHANGELOG.md` 0.1.6-0.1.10) — not a wholesale import of the book's full extracted content, only the subset that is (a) genuinely uncovered and (b) checkable from review evidence rather than being process, methodology, or philosophy content.

## What Changes

- `usability`: seven new rules — a control-truthfulness rule (Bait-and-Switch), a post-authentication-redirect-context rule (Wrong Destination), a forced-secondary-action blocking-modal rule (Road Block), a rule against misusing select/dropdown controls for open-ended high-cardinality data (Absurd Input Controls), a bulk-action rule for list/collection management, two navigation rules for breadcrumb trails and structured footer sitemaps on deep-hierarchy sites, and a positive real-time validation-feedback rule for forms.
- `psychology`: two new rules in `attention.md` — a Law-of-Similarity-based rule against disguising ads/sponsored elements as primary CTAs (the mirror-image failure to the existing banner-blindness rule), and a rule against relying on auto-rotating carousels for important content.
- `trust`: three new rules — a trial/subscription payment-timing rule (no card upfront for free trials, clear pre-conversion notice, self-service cancellation), a mobile-web app-install-interstitial rule (Door Slam), and one generalized mandatory-cost-disclosure-timing rule that applies to any priced flow (subscription, checkout, service signup) without scoping to e-commerce-specific mechanics.
- `product`: one new content rule against double-negative/inverted-logic opt-in/opt-out phrasing (Trick Questions), distinct from the existing confirm-shaming rule.
- Deliberately **not** added, with reasons recorded in `design.md`: the book's strategic/management frameworks (cost-of-fix multiplier, KPI baseline framework, POLA, Agile integration pipeline, service-recovery protocol, backlash dynamics), its testing-methodology content (paper prototyping, inherent-value testing, A/B-testing rules, test-report format), its ethical-philosophy/terminology content (rights hierarchy, "people not users," zero-knowledge architecture stance), several narrow single-case-study patterns that fold into the new generalized cost-disclosure rule instead of getting their own rule IDs, and the book's full e-commerce/checkout vertical (faceted search, checkout-flow architectures, cart UI).
- `README.md`'s "Evidence base" section gains this book as a cited source; `CHANGELOG.md` gains an entry in the same style as prior comparison-pass entries, naming what was added and what was deliberately scoped out and why.

### Modified Capabilities

- `ux-crux/usability`: adds requirements for control-label truthfulness, post-auth redirect context preservation, blocking-modal forced-secondary-action prevention, appropriate control types for open-ended data entry, bulk list actions, breadcrumb/footer navigation aids, and positive real-time form validation.
- `ux-crux/psychology`: adds requirements for visual honesty between ads/sponsored elements and primary CTAs (Law of Similarity), and against relying on auto-rotating carousels for important content.
- `ux-crux/trust`: adds requirements for trial payment-method timing/cancellation, mobile-web app-install interstitials, and mandatory-cost-disclosure timing in priced flows.
- `ux-crux/product`: adds a requirement against double-negative/inverted-logic opt-in/opt-out phrasing.
